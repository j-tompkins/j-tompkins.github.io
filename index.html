Projects

This portfolio is organized into tracks that reflect my focus areas—SQL, Power BI, Python & GIS, and Machine Learning/Data Engineering. Each track documents projects step by step, explaining the choices I made along the way rather than just showing final outputs. Current projects include dashboards built in Power BI, species richness mapping in Python and QGIS, and exploratory work on public health datasets. In the months ahead I will be adding a machine learning project using California health data (Healthy Places Index) and a data engineering project that explores APIs and pipeline design, expanding the site into more advanced reporting and modeling. The goal is to show both the work I have done and how I think through data problems as I build my skills.
