Classification modeling

Healthy Places Index: Homelessness Classification

Python • Logistic regression • Weighted classification • Model evaluation

A classification project using California Healthy Places Index encounter summaries to predict whether an encounter was associated with homelessness. The analysis emphasizes transparent preprocessing, dummy coding, class imbalance, threshold selection, and interpretation of logistic regression results.

California Aquatic Rare Species Richness

Python • GeoPandas • HUC12 watersheds • Choropleth mapping

A reproducible GIS project mapping aquatic rare-species richness across California watersheds. The work compares categorical rank and continuous richness maps while documenting spatial joins, data-format choices, and cartographic tradeoffs.

Tableau • California counties • Broadband adoption • Poverty
