Project Overview

This project explores California’s aquatic rare species richness dataset (ACE ds2748) at the HUC12 watershed level. It includes exploratory data analysis (EDA) and static choropleth maps created using Python and GeoPandas.

Mapping Decisions and Takeaways

A key part of this project was making decisions about data formats and mapping approaches. I started with the California ACE ds2748 dataset in CSV form and explored whether to use Shapefiles or GeoJSON for spatial joins. Shapefiles are still common in GIS, but they come with multiple sidecar files and some quirks (field length limits, encoding issues). GeoJSON, on the other hand, is a single text-based file that is easier to manage, integrates smoothly with Python and web tools, and is well suited for portfolio projects. After weighing the tradeoffs, I used GeoJSON for this analysis. The decision was not just technical—it reflects my learning process and awareness of how choices in data format affect workflow and reproducibility.

The choropleth maps themselves were created with GeoPandas. I chose to visualize both a categorical rank map and a continuous richness map. This combination provides an overview (easy for non-technical readers to grasp) alongside more nuanced detail (useful for analysts and scientists). My next steps are to experiment with classification methods(quantiles, Jenks natural breaks, etc.), refine color choices for clarity and accessibility, and document these experiments as a “choropleth choices” guide for future projects.

I also plan to strengthen my GIS toolkit by practicing with QGIS, which is widely used in the public sector as an alternative to ESRI’s ArcGIS. This will include recreating my maps in QGIS, exporting layouts, and experimenting with symbology and legends. By combining Python workflows with QGIS practice, I can demonstrate both reproducible code-based methods and practical cartographic skills.
